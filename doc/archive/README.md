# Archived design documents

These pages describe the pre-implementation design. They predate most of the shipped
generator, describe features that were never built, and are **not** a requirements
source or an authority for decisions. They are kept for history only.

What SharpCpp supports is specified by the E2E fixtures in `tests/SharpCpp.Tests.E2E`.
New documentation will be written from the shipped code once the architecture work
listed in `PROGRESS.md` lands.
